# jawata-mcp v4.4.8

**Every tool name the engine ever published is answered with its replacement, and the engine's own sentences no longer send a client to a tool it retired.**

## What went wrong

- **35 retired tool names still answered a bare "Tool not found".** 4.4.7 made the replacement pointer reach the client, but the table of retired names had been written from memory and held 20 of the 65 names that have been retired. Derived from each release's own registered tools, 109 names have been published: 44 are live, 65 are retired. Ten of the missing names were only covered by a prefix guess, one of them with the wrong pointer (`inspect_refactoring` was answered "inspect").
- **The engine told clients to call tools it had retired.** Refactoring responses said "undo_refactoring with the undoChangeId if verification fails", search hints said "get_type_members for type results", shared parameter text said "see list_projects" and "apply_refactoring call", error prefixes said "extract_method refused this selection". A client that followed the hint met the not-found answer above.

## What changes

- **The table holds all 65 retired names.** Each pointer names the front door and the kind or action (`undo_refactoring` is now `refactoring action=undo`, `get_type_members` is `inspect kind=type_members`). The two prefix guesses are gone: they answered for names nobody published.
- **`build/published-tool-names.txt` is the record** of every name ever published, derived from the git tags by `build/derive-published-tool-names.py` (run it at each release). A test checks it against the live registry in both directions, requires the table to hold exactly the retired names, reads the live tools' input schemas to fail a pointer whose front door or kind the tool does not accept, and asks every retired name through the protocol. It failed 4 of 6 against the old table and passes 6 of 6.
- **The engine's own text names only tools it publishes.** 157 string literals in 91 source files and the published description of `hierarchy` now name the live call. A second test reads every published description, every input schema and every string literal in the engine's source and fails on any retired name that is not also a live value. It found 171 literals and 4 published texts before the rewrite, and none after.

## Known limits

- **The test cannot see prose in a retired tool's own unpublished description,** because no client can read it. It covers everything the engine publishes or emits.
- **jawata-studio does not yet read the record.** The studio's rule block and guard script were fixed by hand in 4.4.3 and a studio test pins them; the studio taking the record from this file, and failing its own release when it differs from the engine's, is the next studio release.

Works with jawata-studio 4.4.3.
