# jawata-mcp v3.11.0

jawata now records what went wrong here — as shapes, never as your code — and a
tool that says it works without a loaded project finally does.

## The field recording

Every tool call jawata answers now leaves one sanitized line in
`<workspace>/field/pile.jsonl`: which tool, which kind, whether it worked, the
error CODE if it did not, a latency bucket, the client, the version. Nothing
else can be there, because nothing else can be constructed: the record type
holds only whitelisted identifier tokens and a parsed version, so a file path,
an error message or a symbol name cannot pass into it. A corpus of eighteen
would-be leaks — absolute paths on two operating systems, exception messages
carrying identifiers, fully-qualified names, repository URLs, token-shaped
strings — is pushed through every input of the recording path on each build,
and none of them appears in what is stored.

The point of recording is the question nobody could answer before: is the agent
actually reaching for jawata, or falling back to text search? Which tools error
here? Which channels have quietly stopped emitting? jawata-studio shows the
answers; nothing leaves your machine.

## The `field` tool, and `/report`

A new tool, `field`, answers three things: the local recording ranked by which
error shape recurs most, a mark that a shape has been reported, and two
switches — one for the in-session pointer, one for the periodic reminder. They
are deliberately separate: turning off one must never silence a channel you did
not ask about.

The `/report` command drafts a bug report from that recording, shows you the
exact body, and posts it **from your own GitHub account** only after you say
yes — including when an agent invoked it. There is no credential of ours
anywhere in that path.

## A tool that needs no project is no longer refused

`debug`, `profile` and `field` all declare that they answer about the runtime
rather than the model. That declaration was silently undone one branch later:
whenever no service existed at all, they were refused with "no project loaded" —
exactly the moment an agent reaches for them. Two consequences shipped with the
fix: `profile`'s two model-resolving actions now answer their own typed refusal
instead of an internal error, and the base class's promise that the service is
non-null is corrected to say what is actually true for the three tools that
declare independence.

## The seam speaks a version now

Every response carries a contract version, and the client hooks send theirs.
A present-but-different echo is a typed, counted refusal to inject rather than
silence — the shape of the outage where one side's meaning changed, both sides
stayed green, and the capability between them was dead for two weeks.
