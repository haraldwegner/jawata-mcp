# jawata v3.14.1

The patch v3.14.0 earned by being used. Every defect below was found by
dogfooding the release on the live store the same day it shipped, fixed with a
revert-control (revert the fix and a named test goes red), and verified by an
independent external audit before this release.

## Fixed

- **Two verbs existed and could not be found.** `review_sweep` and `delete`
  dispatched correctly and appeared in no published schema — for an MCP door,
  dispatchable-but-unadvertised is the same as absent, and `review_sweep` is the
  only reader of the usage ledger. Both are now in the `experience` tool's kind
  enum, and a test pins the invariant in both directions: every dispatched kind
  is advertised, every advertised kind dispatches.
- **A missing embedding scored as maximally dissimilar.** During the start-up
  backfill (~30 min on a real store), an entry with no vector yet scored 0 on
  all three meaning lanes — the same number as an entry that means the opposite —
  so the best-fitting entry could sink in the ranking while the response said
  the lanes were fine. The nomination now reports `meaning_coverage`
  (embedded/entries) and carries a PARTIAL warning with the numbers when
  coverage is short. The scoring itself is unchanged.
- **The nomination told the reader to judge by situation, then returned rows
  that have none.** The message now counts the unsituated candidates and says
  what to do with them instead.
- **An upstream pattern edit duplicated the catalogue instead of updating it.**
  "A newer jawata proposes, and never overwrites" — only the first half had ever
  been tested. On re-seed, a changed pattern's previous version is now marked
  superseded (kept, not deleted — reversible) before the newcomer is written,
  and the start-up line reports how many versions were retired.

## Added — the store can be repaired, not only diagnosed

- **`experience(kind=set_form)`** — rewrite an entry's situation (and, for an
  experience, its outcome) through the same form gate `record` runs. A verdict
  on a fact is refused, not ignored; an unknown id is refused by name; a
  rewritten row is stamped `provenance_kind=seat_rewritten` so a reviewed
  correction is always distinguishable from the author's own words, and its
  stale vectors are cleared so the backfill re-embeds the new text.
- **The quality lane on `review_sweep`** — beside what nobody uses and what is
  asked for and missing: what is badly written. Its counts are `migrate_form`'s
  own dry-run counts by construction (no third number), and every finding
  carries its `source_ref` — the fact that decides whether the durable fix is
  the file behind the entry or the store itself.
