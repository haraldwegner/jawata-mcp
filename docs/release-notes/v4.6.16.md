# jawata-mcp v4.6.16

**Closes ways around the file access check, says when a chat conversation could not be saved, and fixes several answers that reported nothing while something was there.** Needs jawata-studio 4.6.20 and jawata-chat 0.2.16.

## Access check (update recommended)

- **Windows:** with the shipped policy, every call that named a file or folder was refused, because the policy lists Unix folders such as `/tmp` and one entry Windows did not accept made the whole policy unusable. Such entries now name nothing on Windows and the rest applies, also to a policy file you already have.
- A search of a folder, and many other arguments that name a place, were not checked: a search could return lines of a file that a direct read refused. Every argument that names a place is checked, and a search leaves out each file the policy does not allow and says how many.
- A write through a folder link followed by `..` could land outside the place that was checked. The check and the writer now resolve a path the same way.
- The files tool took a relative path that was checked in a workspace folder and opened in the engine's own folder. It now needs an absolute path.
- A link named like a document no longer lets the files tool change code, and a memory load no longer reads a denied file, directly or through a link.
- **New in the shipped policy:** Gradle's library folder (`~/.gradle/caches`) is open; Maven's `~/.m2/settings.xml` and `settings-security.xml`, which hold passwords, are closed. **Your existing policy file is never overwritten:** add `${home}/.gradle/caches` to `allow`, and `${home}/.m2/settings.xml` and `${home}/.m2/settings-security.xml` to `deny`, yourself.

## Chat and agents

- The chat says once, in the conversation, when it could not be saved to History, and why. Before, a failed or switched-off save looked like a success.
- A new chat and a side discussion start on the agent the Seats page shows; a choice that cannot be read is said instead of replaced.
- An agent set because an editor window reopens its conversation is not stored as your default.
- A hire's report is no longer lost, or its lead left waiting, when the hire ends just as the lead learns of it.
- A hire's card counts Antigravity's engine calls as jawata calls and shows the engine's message for a failed call.

## Answers that were silently empty

- The reflection scan searched only one of its twelve methods and only inside libraries. It now searches your own code for all of them, honours `filePath`, and says what it could not search or had to cut.
- A summary of the reflection, `throws` and `catches` scans answered a total of 0, a whole-family run dropped their results, and `excludePaths` did nothing for them.
- A family quality run now names the scans it could not run.

## Known limits

- A conversation reopened after a restart, or from History, shows its earlier messages, but the agent does not remember them.
- Windows and macOS are run by CI, not by hand.
