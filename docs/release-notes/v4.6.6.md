# jawata-mcp v4.6.6

**The chat names the model that is answering.**

## What changed

- **After you pick another brain for the principal, its row no longer shows the previous brain's models.** In 4.6.5, picking Claude Code while Cursor's agent was running left Cursor's model list on the row, named as Claude's, with Cursor's model ticked; Claude answered on its own default. Now the row names the picked brain alone until its own session opens, and the turn that opens it tells the chat that brain's own models and the one it is on.

This release carries no other change of the engine; it is 4.6.5 with its CI fixes and this one.

## Known limits

- Checked on Linux, in a sandbox engine with Claude Code's adapter and Cursor's agent as real brains. Windows and macOS builds are produced but were not used by hand.
