## jawata-mcp v4.0.0

**Why the major.** Finding text changed on multiple smell kinds, and the
refactoring surface gained kinds that did not exist before. Both are contracts
somebody reads — a message a person or an agent acts on, and a published kind
list a client dispatches against — so the version says so rather than hiding a
shape change in a patch digit.

**Every kind that declares a cure now renders one.** Twelve smell kinds declare a
cure; one rendered it fully, two rendered a stripped form built from the same
rows, and eight rendered nothing at all, because a single registry received the
experience store and passed it to a single detector. The store is now threaded at
the one point every registry's output passes through. The sharpest symptom was
not a missing detector: `ocp` holds the switch-statements and type-code detectors
and relabels their findings, so one measurement, at one line, answered richly
under `ocp` and bare under its own kind.

A detector that reaches no store now reports itself DEGRADED rather than quietly
printing a hardcoded hint. The silent default was what shipped until now.

**Kerievsky ranks 2 and 3.** The refactoring set extends past Fowler: Extract
Class follows its readers across a file boundary, Replace Conditional with
Polymorphism is wired under the guard, and the arms of a decomposed conditional
take the method's scope with them or the operation refuses. Rank 3 is staged and
applied on both sides of the call, with undo and a purity check closing its
per-operation gate. The round trip is the identity on six originals we did not
author.

**The catalogue is rebuilt.** 187 rows gained a family, and 76 entry-point
addresses that pointed at nothing now resolve. A cure's tier is DERIVED from
route count and step existence rather than assigned, so a table that lies cannot
load.

**Two release gates that fire on their own.** A patch-streak gate stops the
second release of a run of patches and asks for the architect — the two such runs
this project has had (nine tags on 2026-08-13, four on 2026-08-29) were one design
flaw being moved around each time. The suite refuses to start beside a competing
heavy job, because that contention manufactures failures indistinguishable from
regressions; the first version of that guard was a load threshold that would have
gone green on the very run that motivated it, and was replaced after its own
control run caught it.

Sharded suite: 2241 total, 2239 succeeded, **0 failed**, 2 corpus-gated skips.

Those two skips are unchanged since at least v3.9.0 and are now understood: they
need a knowledge-store corpus that is not committed, so they announce that they
did not run rather than passing on no data. The repair — cases authored as
Markdown, loaded through the ordinary reader into a throwaway store — is recorded
as findings 13 and 14 in `docs/sprints/dossier-28d-carried-findings.md` and homed
to Sprint 28e.
