## jawata-mcp v3.10.0

**The resident's bearer token stops travelling on the command line.** On a
shared machine any process can read another's arguments — on 2026-08-17 a
foreign agent read two residents' URLs and tokens out of `ps aux` and started
calling the endpoints. `-token-file PATH` is now the token's HOME: the engine
READS the token from that file when it exists and GENERATES it there `0600`
when it does not, so nothing sensitive needs to reach argv. A named-but-unusable
file refuses the start rather than inventing a token no client holds — a
silently different token would 401 every configured client with no explanation.
The READY line names the file (or says `token=provided`) instead of printing the
secret, because the manager tees stdout into a log that outlives the process.

**A workspace whose projects failed to load is now a state the engine
understands, not an accident it trips over.** Filed as three defects, they were
one absence: on such a workspace the service object exists and is empty, so
`search_symbols` dereferenced a null search service and answered
`INTERNAL_ERROR — this may be a bug` (mcp#28), `health_check` computed
`workspace.healthy` over the empty project list and said *true* while its own
`project.status` said *failed* (mcp#29), and the workspace identity introduced
the failed projects as present (mcp#32). The tool gate now asks whether there
are projects to answer from — never the loading enum, which is sticky and would
refuse a workspace that has since recovered — and the runtime tools (`debug`,
`profile`) keep working, because they read a JVM or a crash log rather than the
model.

**Recall can see what the agent just wrote.** A cue whose fit set overflowed the
cap served five older entries and omitted the marker recorded seconds earlier
(mcp#34). The cause was not the cue kind it was reported under: meaning entered
the ranking as a raw cosine score above recency, and two texts never tie on a
continuous score, so recency was unreachable whenever the embedder is on.
Meaning is now quantized into bands — it breaks real ties, as its own contract
always claimed — and the cap reserves one slot for the newest fitting entry.

**`inspect(kind=source)` returns a readable page instead of a reply the client
refuses.** `java.util.stream.Collectors` came back at 98,064 characters and was
rejected outright. It is now paged: `maxChars` (default 24,000) and `offset`,
with the full `sourceLength` always reported and a truncated reply naming the
exact next call — the same idiom `compile_workspace` and `find_quality_issue`
already use.

Full serial suite: 1839 tests, 1833 passed, 0 failed, 6 assumption-gated skips.
