# jawata-mcp v3.7.2

The engine's first release verified on all three operating systems.

## Windows users stop seeing their home directory in diffs

Relativising a path compared two spellings of the same directory and, when
they differed, fell back to the absolute path. On Windows — where symlinks
and short names make different spellings routine — every refactoring diff
could show `C:\Users\<you>\...` instead of `src/main/java/...`. Paths are now
resolved through the filesystem's real spelling before comparing, verified by
a test that fails on the old code.

## Profiling sessions clean up after themselves on Windows

A launched JVM's flight-recording repository was deleted once, best-effort,
immediately after the process was killed — and Windows releases a killed
process's file handles late, so the delete quietly left recordings behind.
Teardown now checks that the process actually exited and retries the delete
with a bounded backoff, logging honestly if anything remains.

## The cross-platform test matrix is real now

The three-OS CI matrix (Ubuntu, macOS, Windows) had existed for months and
never executed once. It now runs on every push and is green on all three:
1,783 tests, zero failures per platform, with every platform-specific skip
recorded as an explicit assumption naming its reason — never counted as a
pass. Line endings are pinned at checkout so the byte-exact refactoring
parity tests compare identical inputs on every platform.
