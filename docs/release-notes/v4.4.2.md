# jawata-mcp v4.4.2

**A hired Claude no longer has its own built-in tools, and the hire record tells a refused attempt from a call that ran.**

## What went wrong

- **A hired seat could use tools its file never listed.** 4.4.1 gave a hired Claude only the jawata engine that hired it, but its own built-in tools stayed available. A PM seat whose file lists read operations only, told to edit a file, used Bash three times, started a sub-agent, and wrote a plan file outside its working folder. It never called a jawata tool.
- **The hire record's containment line was out of date.** It said a Claude hire is "NOT write-contained by a mechanism".

## What changes

- **A hired Claude starts with no built-in tools** (`--tools ""`). In 10 hires of the same PM seat told to edit a file, no file was written anywhere and no plan file appeared. In 9 of the 10 the brain still tried a built-in tool by name, such as Write, and said it was unavailable.
- **The record separates an attempt from a call.** The CLI announces what it offers when it starts. The record now carries that list as `toolsOffered`, and a call to anything not on it is listed as `attemptedButNotOffered` and left out of the code-changing, shell and unclassified counts. In the last 4 hires the no-code-change reading was complete, where before a refused Write made it read "1 code-changing call".
- **The record's containment line states what was measured.** It names the flag, says "measured, not proven: 10 of 10", and says the resident's other jawata tools are still offered.

## Known limits

- **The seat's tool list does not hide tools.** The CLI offered all 44 of the resident's jawata tools, and the seat's list only pre-approves some of them. Whether the others are refused rests on the read-only permission mode, which this release did not exercise.
- **Ten hires are an observation, not a guarantee.**
- **Only an HTTP engine gives a Claude hire this start,** and only Claude's start-up list is read. A stdio engine keeps the user's own setup. Cursor, Copilot and Codex hires are unchanged and still count attempts as calls.

Works with jawata-studio 4.4.1. No studio release is needed: studio installs the latest engine.
