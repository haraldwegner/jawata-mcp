# jawata-mcp v4.6.1

**The chat shows which model is answering, and you can change it.**

## What changes

- **The principal's row names the model it runs on**, for example "cursor · grok-4.5". The name is what the agent itself reports for its session, not what a setting says.
- **A model is chosen from the row.** The list holds every model the agent offers; choosing one moves the same conversation, and the principal answers from it from the next message. A model the agent does not offer is refused with its name and nothing changes.
- **The principal's setting may name a model** beside its command (`"model": "grok-4.5"`). It is applied once the agent's session is open; a model the account does not have leaves the agent on its own default and ends nothing.
- **The chat is told once the session is open**, because that is when the model becomes known; before, the row read only the brain's name until a reload.

## Known limits

- Cursor's agent ignores `--model` when it is started in ACP mode, so a model is chosen only through this setting or the row.
- Checked on Linux with Cursor's agent and a stand-in agent; not run with Claude's or Codex's adapters, which are not installed on the machine it was checked on.
