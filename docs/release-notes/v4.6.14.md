# jawata-mcp v4.6.14

**Antigravity (`agy`) is a brain, and the engine no longer refuses a brain the person chose: a stored choice of a brain whose writes no mechanism holds back is the consent, and the answer still says the writes were not contained.** Needs jawata-studio 4.6.18 and jawata-chat 0.2.14.

## What changes

- **Antigravity is a brain.** `agy` is started as `agy --output-format stream-json [--model <m>] -p=<prompt>`, offered in `brains(action=status)` with its login check and its login command (`agy acp --login`), and in the chat's list of brains it can run on (`agy acp`). Grok is no longer a brain: it is merged with Cursor, and Cursor is shown as Cursor-Grok.
- **A stored choice is the consent.** Since 4.6.13 a hire of Cursor, and now of Antigravity, was refused for want of an opt-in line in the seat file that the Seats page no longer wrote. A hire now takes the stored choice of such a brain as that opt-in, and the hire's answer still reports `writeContainment` and its basis, so the person sees the writes were not held back. The Seats page, not the engine, warns the person on a seat that must not change code.
- **A seat row says whether the seat changes code** (`changesCode`), so a screen can warn only where it matters.
- **A turn on a brain that opens no session says so.** The principal's reply names the brain, what the brain said, and how to connect it (press Connect on the Seats page in jawata studio, or run its own login), and is no longer silent.
- **Test hardening:** `PrincipalBrainTest` drives a real turn against a stand-in agent whose login never succeeds and asserts the sentence reaches the host; the stand-in gains that mode.

## Known limits

- **Antigravity writes are not contained.** Measured on `agy` 1.5.15 (Google AI Pro): in its default mode it wrote a file when told to in 5 of 5 print-mode runs and 3 of 3 ACP runs without asking; `--mode plan` held in 8 of 8 runs but made no tool call in 2 of 2 ACP runs, so a hire cannot use it. A hire on Antigravity cannot be told which tools to attach from the command line.
- **Antigravity's 100-tool limit does not apply to its command line:** 51, 101 and 153 tools registered from stdio servers and calls past the 100th reached the server. An HTTP entry with a bearer header was reached with the header on every request (initialize, tools/list and a tool call). Measured with a local server; a real jawata engine entry in Antigravity's global config file was not run.
- **Any agent can store a seat onto a brain whose writes are not held back** (`brains(action=set)` checks only that the brain is known), and with the stored choice as the consent nothing refuses it. Recorded as an open edge.
- Not run in a real studio or chat window: the Connect button with a real Antigravity login, and a real Antigravity or Cursor hire reading the stored choice.
