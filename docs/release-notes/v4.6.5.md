# jawata-mcp v4.6.5

**The chat answers what it was asked: the review that rewrote and held every answer is gone, and the main seat's default model is set in its seat file.**

4.6.5 replaces 4.6.4. The 4.6.4 tag exists but has no release: its build ran out of time on GitHub's runners with no test failing. 4.6.5 carries the same changes plus the fixes below.

## What changes

- **The main seat's text reaches the person as the brain wrote it.** Until now every answer went to a second brain session that rewrote it to "open with the decision" or held it. Asked "Who are you?", the person got the reviewer's note ("Send nothing. The draft asks for no decision.") or a held-message sentence, after 43 to 57 s. Now the answer arrives as written; measured on Cursor's agent, the first word comes 6 to 9 s after a typed "Who are you?" in a new chat. Most of that time is the brain reading the main seat's text with the first message. The setting `jawata.agent.reviewer` (`JAWATA_AGENT_REVIEWER`) is no longer read.
- **The main seat's file names its default model** (`model:` beside `brain:`), and a new conversation starts on it. The studio's Seats page writes it.
- **`run_tests` no longer loses the last lines of a test run's output on a slow machine.** The reader that collects the output tail was locked out while the test process was still writing, so the final lines could be missing from the answer. A new test fails without the fix.

## Build and test fixes

- The release and CI test steps may now run for up to 240 minutes, not 100. GitHub's runners currently run the suite about 2.4 times slower than before. The limit stops a hung run; it is not a time budget.
- Tests that wrote Linux-style paths or read the console in the system encoding now also pass on Windows. These were the DAP, LSP refactoring, LSP testing and ACP lead-loop tests.
- Test projects are released before they are copied again, so a second copy does not fail on Windows while the first is still open.

## Known limits

- The first answer of a conversation still carries the main seat's text, about 5 s on Cursor's agent; later answers do not.
- Checked on Linux. Windows and macOS are checked by this release's CI run.
