# jawata-mcp v4.4.7

**A retired tool name the engine's table knows now reaches the client with the tool that replaced it.**

## What went wrong

- **A client that called a retired tool name got a bare "Tool not found".** The registry already built "Tool not found: X. Did you mean 'inspect'?" from its table of retired names, and the protocol handler caught that exception and threw a new, bare message, so no client ever read the pointer. All 16 retired names tried against the published 4.4.6 (for example `analyze_type`, `get_type_members`, `extract_method`, `undo_refactoring`) answered with no replacement. The tests that passed called the registry directly, so the handler was never on their path.
- **The new embedder-off CI job found two tests that failed without an embedder.** A backup test counted one row more than it read from a copy taken while something was writing, and the map test lost its area line when ranking fell back to words alone.

## What changes

- **The protocol handler throws the registry's own message.** A test asks every retired name the table lists through `processMessage`, the way a client does, and fails if any reaches the client without its replacement; a name that was never a tool still gets no invented pointer.
- **The backup test measures the rows a copy holds,** not the statistic, and lets the count be ahead by the one row in flight and no more. **The map test skips without an embedder,** worded the way the embedder-off abort budget accepts.
- **Not product code:** the jawata.org page was rebuilt, and the patch-streak check on this machine now asks and logs instead of counting tag numbers.

## Known limits

- **Five of the 16 retired names tried still answer a bare "Tool not found".** `undo_refactoring`, `apply_refactoring`, `get_type_at_position`, `list_projects` and `add_project` have no entry in the engine's table of retired names, and `inspect_refactoring` is answered "inspect", which is wrong (the live call is `refactoring(action=undo)` and its siblings). The fix's test loops over the table's own names, so it cannot see a name the table lacks. A completeness check against every name ever published is the next release's work.
- **The pointer was measured over HTTP only.** Whether a client's own error text hides it is not measured.
- **A copy of the store taken while something writes can report a row count one ahead of its rows.** Every row reads; the count is one too high until recomputed.
- **Without an embedder the map a task opens with can lack its area line,** because ranking falls back to words alone. The embedder is on by default.

Works with jawata-studio 4.4.2.
