# jawata-mcp v4.6.8

**History lists your conversations from every client, ten at a time.**

## What changes

- **The chat's History lists the person's conversations from every client**, not only the chat's own. Each row names its client (jawata, Claude Code, Cursor). Since 4.6.7 History listed only the sessions the chat itself recorded, which left out the Claude Code sessions you work in.
- **Sessions the engine started for a brain are left out.** The engine gives every brain it starts (a hired seat, the principal's own) the variable `JAWATA_MACHINE_SESSION`; the studio's hook (4.6.10) writes such a session under a client name with `-machine` after it, and History skips those. Sessions written before the mark existed are told by their first words (the principal's or a seat's own prompt), which is a guess.
- **The list comes in pages of ten**, newest first, with a cursor for the next ten (`session/list` carries `nextCursor`). The page size is the engine setting `jawata.agent.historyPage` (environment `JAWATA_AGENT_HISTORY_PAGE`), ten by default.
- **Opening a session another client recorded** shows its recorded turns; a new message there starts a fresh conversation with the principal's brain, because that client's own memory of it is not resumed. The chat says so.

## Known limits

- The old mark is by first words only, so a machine-made session written before this release that does not start with a seat's prompt may still show.
- Not run on Windows or macOS by hand; CI runs them.
- The known unfixed limits of Stage 26 listed in the 4.6.7 notes stand.
