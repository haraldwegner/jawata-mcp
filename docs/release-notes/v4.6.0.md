# jawata-mcp v4.6.0

**The chat is usable for real work: the `/` list shows your seats and skills, short questions answer much sooner, you can replace the agent doing a job while it runs, and pictures reach the agent.**

This is a minor release on 4.5.2. The tool list is unchanged (46 tools); what changed is how the engine behaves as the agent behind a chat.

## What you can do now that you could not before

- **Pick a seat or skill from the `/` list.** The engine now tells the chat which seats and skills exist, grouped. Seats nobody types (the observer and the worker's kind) are left out.
- **Replace the agent doing a job.** Choosing another brain on a running hire stops that hire and starts the same task on the new brain with the conversation so far. The agent that hired it is told it was a replacement, not a failure, and the seat's default does not change.
- **Send a picture.** The engine says per brain whether it takes pictures, and passes them on as pictures to those that do.
- **See which brain answered.** A hire's entry names the brain that actually did the work.

## Behaviour changes

- **One agent program per conversation** instead of one per message. On the machine this was measured on, opening a conversation went from 5.48 to 7.30 s down to 1.96 to 3.79 s, and the first answer from about 6.4 s down to 1.50 to 4.26 s.
- **The chat's agent is jawata.** The main seat's text reaches the brain with the first message, and a greeting or a plain question is answered at once, without a tool call.
- **The agent works in the folder the chat opened**, not in the folder the engine happened to start in.
- **Stop reaches the agent that is answering** when it is pressed over the wire.
- **The per-seat model options are gone from the chat's agent settings.** Which brain a seat uses is chosen where the seats are configured, or replaced on a running hire as above.
- The chat's log names the engine's real version.
- The Java language server answers the project tree that the Java Projects view of the editor extension shows.

## Known limits

- **Checked on Linux only.** Not run on Windows or macOS.
- **A hire longer than about a minute under a Cursor principal** shows as failed in the chat, because Cursor gives up on the call. The hire itself goes on.
- A brain that cannot connect to a tool service over HTTP is given no jawata tools.
