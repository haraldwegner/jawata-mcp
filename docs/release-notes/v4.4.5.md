
# jawata-mcp v4.4.5

**The experience store is copied every day, and the copy is read back before it counts.**

## What went wrong

- **A copy was taken only before a destructive verb.** On 2026-10-14 the newest copy of the user-level store was a month old, while the store was written to every day and then corrupted. The only way back was that old copy.
- **A hired brain's short reply was doubled.** A one-turn reply arrives twice from Claude and Cursor, once as the assistant line and once as the closing result line, and both were collected: a brief asking for one word was answered "READY\nREADY".
- **`experience delete` could not be called from a client.** The verb requires a parameter named `ids` and the published schema never declared it, so every client call failed with INVALID_PARAMETER and an agent could not remove a malformed entry it had written. `promote_rule` reads the same parameter.
- **A hired seat could not ask which tests a change reaches.** `run_tests` is refused to a hired Claude in plan mode, so both test-manager hires answered from the call graph and not from the impacted-test selection the clause names.
- **A profiler test failed once on CI.** `HotspotTest#wallDimensionRanksBlockingWallTimeNotJustCpu` failed because the target program's CPU burn was an iteration-counted loop, so the number of samples a recording drew depended on how fast the machine was: 3 to 11 on the development machine, zero once on a fast CI runner.

## What changes

- **A daily copy.** Each engine checks at start and then hourly, and takes a copy when no scheduled copy exists or the newest is a day old. Scheduled copies keep their own depth (14), separate from the pre-verb copies (10), so a burst of wipes cannot push the daily copies out and a run of daily copies cannot push out the copy taken before a wipe.
- **A copy is read back before it counts.** Every scheduled copy is read through to its end and must hold a database file; one that cannot be read back is deleted and logged.
- **`experience stats` carries a `backups` block:** how many copies, which is newest, how old the newest daily copy is, and whether another is due.
- **A one-turn reply is the answer once.** The closing result line is marked terminal and its text is kept only when nothing else was said, so a multi-turn answer keeps every turn and a run whose only text was an error message still reports it.
- **`ids` is declared** in the published schema for `delete` and `promote_rule`.
- **`inspect(kind=impacted_tests)`** answers the impacted-test selection on a read-only door. It is the same implementation `run_tests` uses, reached from a second door, and a door nobody wired refuses with the reason and never answers an empty list.
- **The profiler test's target burns 5 ms of time per cycle** and not a fixed number of iterations: 25 to 36 samples per 5 s recording.
- **The README's list of `inspect` kinds** names all thirteen.

## Known limits

- **The daily copy has no test of its failure branch.** A copy that cannot be written, or that is written and cannot be read back, is deleted and logged; no test makes that happen. Four of the six backup tests turn red when their behaviour is put back; the status and in-memory cases were not mutated.
- **There is no write journal and no copy off the machine.** The daily copy is a file beside the store, and a disk failure takes both.
- **The first daily copy appears at the first check after an engine restarts on this version,** and the `backups` block only exists on engines running it.
- **`inspect(kind=impacted_tests)` needs coverage evidence recorded with attribution.** Without it the answer says `attributionAvailable: false` and narrows nothing. No hired test-manager run has used the door yet.
- **The profiler fix is measured, not proven by a failing run.** The old failure needed the whole-suite context and was not reproduced in isolation; the measured sample counts and 8 of 8 passes at a 2-CPU cap are the evidence.
- **Only a one-turn duplicate is removed.** Two consecutive identical assistant turns are both kept, as they were.

Works with jawata-studio 4.4.1. No studio release is needed.
